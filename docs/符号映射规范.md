# 早期符号映射记录

> **历史参考**：下表保留原有映射，不作为新的语义规范。部分映射混合了条件与原因、事实否定与禁止、空集与 null、顺序与变更，使用时存在歧义。当前固定规则使用具有明确关系和作用域的公共表达，详见[轻量语义压缩与用户词典设计](design/semantic-compression.md)。本表不参与编译，旧预设文件也不再加载。

### A. 逻辑与条件运算符（替代连词与从句）
→ / ⇒：因果 / 动作流向 / 触发（替代“如果…那么…”、“接着”、“导致”、“用于”）

∧ / +：逻辑与 / 并列组合（替代“并且”、“同时”、“以及”）

∨ / |：逻辑或 / 枚举选项（替代“或者”、“包括但不限于”、“以下任意一种”）

¬ / !：逻辑非 / 禁止（替代“不要”、“禁止”、“未…”、“不进行…”）

∀：全称量词 / 遍历（替代“对每一个”、“遍历所有”、“逐一”）

∃：存在量词 / 命中（替代“只要存在”、“一旦发现”、“命中其中之一”）

∈ / ⊆：属于 / 包含于（替代“属于某类”、“在…范围内”）

### B. 状态与数据操作符号（替代动词短语）
:= / =：赋值 / 定义 / 设为（替代“将其定义为”、“标记为”）

↔ / ⇄：互换 / 变更（替代“把 A 改成 B”、“从 A 挪到 B”）

?：条件判断 / 探测（替代“测试是否…”、“判断能否…”）

⚠ / 🚫：强约束 / 红线警告（替代“务必注意”、“全程严格禁止”）

### C. 结构与层级符号（替代段落与编号）
ASCII 树形线 (├ │ ╰)：替代“首先、其次、最后、第一点”，用视觉缩进直接锚定作用域（Scope），防止大模型把子步骤的约束泛化到全局。

中括号 [] / 尖括号 <>：用于包裹状态标签、角色枚举或参数占位符。
