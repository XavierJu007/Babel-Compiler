# Babel-Compiler 当前路线图

> 更新日期：2026-11-20。项目范围是使用者自行维护专业词典的高密度语义编译小工具。设计与边界见[高密度巴别语与用户词典设计](../design/semantic-compression.md)，操作说明见 [README](../../README.md)。

## 已有基础

独立领域词典、词条编辑与保存、固定编译规则、指定编码计数、可选独立盲读、逐请求验证和代理回退已经提供。专业内容由使用者维护，内置条目用于起步和示例。

固定方案标识为 `mixed`，不增加输出类型或预设编辑入口。默认目标是高密度混语浅树：用公开术语、`role` / `goal` 等短标签和公共符号保留完整关系，省掉句子展开；无私有码本、无图例自解释。专业词典仍由使用者维护，文本 token 减少与实际账单节省分别计量。

“完成”指当前小工具范围内的实现、错误处理与程序回归。模型的真实语义保留率、任意模型的无图例理解能力及总费用收益仍须用实际输入验证；草拟评测案例仍保留待人工复核标记。

## 高密度巴别语纠偏

之前把“自解释”过度收缩成了自然语言短句，对符号和图式表达只给出许可，导致实际目标偏离。当前工作直接调整同一套默认规则：

- 主动提取主体、动作、对象、条件和约束，多分支默认组织为浅树；共享上下文提升为父级作用域，避免只改写措辞。简单单关系仍可保持一行。
- 优先用 `role`、`goal`、`scope`、`flow`、`if` 等常见短标签，在关系层混语，不逐字翻译整篇、不用 meme；业务实体保持一致。
- 主动使用与关系匹配的公共符号；`∵` 只用于原文明示的因果，`¬` 不表示禁止，许可分支中的 `no approval` 表示免审批。`可/may`、`须/must`、`禁止`、`无需` 仍须区分。
- 校验按信息和关系判断，允许等义的图式重排；继续保护技术字面量，不自动修复原文拼写或载荷。
- 修复裸 `not/no/不/未` 被硬判为事实否定、误拒绝等义禁止表达的问题；交给上下文对照，不将未知当成通过。明确的禁止、许可和时态冲突仍受保护。
- README 与输出区明确展示巴别语目标；程序回归与真实模型效果分别记录，不以固定回答的测试替代真实生成质量。

固定策略加入跨领域关系表达示例，通用词典同步紧凑示例。现有评测集的 10 个正例改为图式表达，30 个案例与 60 个错误变体保持原有语义范围；[图式回归](../../babel-go/babel_graph_test.go)与[编译 HTTP 回归](../../babel-go/babel_graph_integration_test.go)覆盖共享作用域、盲读隔离、字面量/边界破坏和模型拒绝传播。

这是既定功能的纠偏，不增加新的模式、配置或平台功能。

## 长 SOP 结构回归

用户反馈完整售后 SOP 去掉一二三后仍按原六章逐句缩写。生成路径改用 `babelStructureIssues`：对有至少两个可识别独立章节标题、非原本紧凑且非受保护格式的原文，要求候选至少有两个带正文的 `├` / `└` / `╰` 分支；代码、引文及空枝不计入。原标题去编号、加冒号、Markdown 样式、树枝或箭头仍会被识别；改名后继续平铺也会失败。该规则是固定格式合同，不用符号密度或压缩率代替语义判断。

形态不合格最多额外重组一次；仍失败则返回明确错误并保留候选供检查，不缓存、不继续审核，代理保留原文。形态不合格的旧缓存不会复用，最终候选仍按本次请求计数和校验。只依据原文决定指定格式、步骤引用和原本紧凑输入的豁免，候选不能靠自加 `Output format:` 放行。纯排版的 `1\.` 等转义编号也纳入识别。

[完整售后样例](../examples/README.md)保存原文、用户报告的平铺坏输出与手写浅树参考，保留金额区间重叠、库存重试原顺序及输入中的孤立字符。引号内的技术字面量继续保护；普通条件和活动描述允许关系式压缩。未引用的纯列表编号不再当作业务数值强制保留，被引用步骤和正文数值不受此豁免。

局部校验同时按高密度表达复核边界：`¬(...)` 不能按内部比较符直接判冲突，不同分支的“无需审批”和审批义务不能机械合并。无法局部确定作用域时继续语义对照，未拦截不代表通过；明确的数值、单位或同作用域冲突仍应拦截。本轮新增回归覆盖如下：

| 回归范围 | 证据 |
| --- | --- |
| 完整坏输出触发一次重组、最终树进入缓存、旧平铺缓存失效、连续失败仍可查看候选 | [dense_restructure_test.go](../../babel-go/dense_restructure_test.go) |
| 命题否定、混语模态与关系的 compare/blind 路由、数值保护和模型拒绝传播 | [dense_contract_test.go](../../babel-go/dense_contract_test.go) |
| `no approval` / `No审批` 的分支作用域、阈值保护及短标签文本计数 | [mixed_labels_test.go](../../babel-go/mixed_labels_test.go) |
| 旧标题的格式变体、有效树分支、源文本豁免与候选自造格式旁路 | [outline_test.go](../../babel-go/outline_test.go) |

本轮 Go 1.22.12 构建、`go test -race ./... -count=1` 和前端 48 项测试全部通过；通过 `BABEL_TEST_BINARY` 启用了实际服务集成，未跳过。新增用例包括跨行否定、不同父级/逗号条件下的同名动作，以及盲读完整引文包含其他分支时的接受和拒绝传播。

这些测试用于验证结构识别、一次重组上限、缓存、模型拒绝和代理回退。共享生成在最后一个等待者退出时取消，避免全部请求已取消后仍追加重组调用，同时保留其他等待者的正常结果。手写参考的分词结果与真实模型生成质量分别说明；集成里的模型回答是本地 fixture，不宣称已用用户上游模型验收。

## 已交付的可靠性修复

- 词典文件与管理请求拒绝非法 UTF-8；明确独立复制、同名覆盖、保存范围和生效来源。
- 部分更新配置时保留未提供的代理上游地址；测试新方案时仅使用该草稿明确提供的密钥。
- 编译请求固定所选方案；原文、领域、计数或校验设置变化后，旧结果及迟到响应失效。配置备份仅在同名方案内沿用密钥。
- 词典重载期间保护草稿；保存/删除/重载成功但后续刷新失败时，明确显示服务端操作结果并保留当前内容，旧编译结果及时失效。
- 所选计数器失败时，通过实际 HTTP 回归确认代理保留原文、透传上游响应并记录回退原因。
- 编译、校验与试连共用请求 URL 规则：完整端点原样发送，主机或 `/v1` 基址兼容补全；缓存按实际请求地址区分，代理上游基址单独处理。
- 引号本身不再触发逐字保护：`「已签收未超过 7 天」` → `签收≤7天`、`参与「满 3 件 8 折」` → `参与(满3件8折)` 可进入语义对照。协议值和固定返回值按值保留，装饰性引号变化交给模型判断；代码、实际 JSON 字符串及显式原样字符串继续保护。这是有限线索检查，不是完整解析器，也不将未知含义直接判为通过。
- 编译失败时保留已生成候选：错误响应包含 `compiled`、`dialect`、`cache_hit`、`stats`、`validation`、`detail`，严格拒绝仍为 `422`、校验服务或格式异常仍为 `502`。Web 展示未通过/未验收候选供检查与复制；代理保留原文继续转发，最终上游自身错误仍真实返回。
- 失败路径复核补齐：流式代理不再自行添加 `stream_options`；生成或重组未完整结束时保留部分文本供检查，错误状态仍阻止缓存和采用；错误中普通提及 `API Key` 不再触发配置弹窗遮住候选。
- 引号局部上下文回归：固定返回值的保护不跨行继承，普通引号标题后的冒号不等同于 JSON，“无需逐字”不再反向锁死文本，后置“须保持原样”继续保护原始拼写。实际 JSON、多行 JSON、赋值、数值和独立的正向原样要求仍受检查。

**上一轮验收记录：** Go 1.22.12 构建、`go test -race ./...` 和前端 48 项行为测试均通过；全量 Go 检查通过 `BABEL_TEST_BINARY` 启用了实际 Babel HTTP 服务集成。回归覆盖普通引号改写与实际字面量保护、截断及失败候选展示、原文回退、流式选项与 SSE 透传、配置弹窗触发边界、无候选清理、无效计量及迟到响应隔离。复验方式见[评测说明](../../eval/README.md#6-实际-http-集成检查)。集成中的模型回答使用本地 fixture，结果不作为真实模型效果分数。

## 范围说明

完整语义图 IR、大规模模型评测矩阵、成本平台和多候选搜索不列入当前计划。已有评测与报告工具保持可选，不扩建为使用门槛；后续扩展由具体使用问题决定。

后续维护围绕同一套高密度表达规则修复可复现问题，使用实际输入检查压缩密度、条件保留和独立理解情况。专业词典由使用者维护；新的领域内容、配置模式或平台能力不会自动加入待办。

本页替代早期工程清单，旧版本可从 Git 历史查看。旧文档中混合估算与完整请求 usage 的“真实账单压缩率”、依据数字出现就给语义绿勾，以及“零泄露”“0ms”等绝对保证均已废弃，不是待完成事项。
