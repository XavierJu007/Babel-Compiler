# Babel-Compiler 当前路线图

> 更新日期：2026-11-19。项目范围收敛为使用者自行维护专业词典的文本压缩小工具。设计与边界见[轻量语义压缩与用户词典设计](../design/semantic-compression.md)，操作说明见 [README](../../README.md)。

## 已有基础

独立领域词典、词条编辑与保存、固定混合表达规则、指定编码计数、可选独立盲读、逐请求验证和代理回退已经提供。专业内容由使用者维护，内置条目用于起步和示例。

| 原计划 | 状态 | 已交付范围与验收依据 |
| --- | --- | --- |

固定方案标识为 `mixed`，不再增加输出类型或预设编辑入口。公共规则继续要求无私有码本、无图例自解释；专业词典仍由使用者独立维护。不为追求符号密度而牺牲语义，也不将文本 token 减少称为实际账单节省。

“完成”指当前小工具范围内的实现、错误处理与程序回归。模型的真实语义保留率、任意模型的无图例理解能力及总费用收益仍须用实际输入验证；草拟评测案例仍保留待人工复核标记。

## 本轮收尾

- 词典文件与管理请求拒绝非法 UTF-8；明确独立复制、同名覆盖、保存范围和生效来源。
- 部分更新配置时保留未提供的代理上游地址；测试新方案时仅使用该草稿明确提供的密钥。
- 编译请求固定所选方案；原文、领域、计数或校验设置变化后，旧结果及迟到响应失效。配置备份仅在同名方案内沿用密钥。
- 词典重载期间保护草稿；保存/删除/重载成功但后续刷新失败时，明确显示服务端操作结果并保留当前内容，旧编译结果及时失效。
- 所选计数器失败时，通过实际 HTTP 回归确认代理保留原文、透传上游响应并记录回退原因。

本轮 Go 1.22.12 构建、`go test -race ./...` 和前端 40 项行为测试均通过。Go 测试已通过 `BABEL_TEST_BINARY` 启用真实 Babel HTTP 服务集成；复验方式见[评测说明](../../eval/README.md#6-实际-http-集成检查)。模型回答使用本地 fixture，结果不作为真实模型效果分数。

## 范围说明

完整语义图 IR、大规模模型评测矩阵、成本平台和多候选搜索不列入当前计划。已有评测与报告工具保持可选，不扩建为使用门槛；后续扩展由具体使用问题决定。

当前约定范围内没有剩余代码开发项。后续维护继续围绕同一套规则修复可复现问题。专业词典由使用者维护；新的领域内容、配置模式或平台能力不会自动加入待办。

本页替代早期工程清单，旧版本可从 Git 历史查看。旧文档中混合估算与完整请求 usage 的“真实账单压缩率”、依据数字出现就给语义绿勾，以及“零泄露”“0ms”等绝对保证均已废弃，不是待完成事项。
