# Babel-Compiler 当前路线图

> 更新日期：2026-11-19。项目范围收敛为使用者自行维护专业词典的文本压缩小工具。设计与边界见[轻量语义压缩与用户词典设计](../design/semantic-compression.md)，操作说明见 [README](../../README.md)。

## 已有基础

独立领域词典、词条编辑与保存、固定混合表达规则、指定编码计数、可选独立盲读、逐请求验证和代理回退已经提供。专业内容由使用者维护，内置条目用于起步和示例。

## 近期维护重点

1. **词典容易写。** 清楚区分术语、适用条件、必须保留的信息和例子；让使用者理解保存位置、覆盖关系和重新加载行为。
2. **结果容易判断。** 原文与候选可对照，计数注明编码或估算，验证状态和回退原因如实显示。所有入口使用同一套规则，是否更短看本次计数。
3. **持续优化一套规则。** 优先修复专业词条被误用、技术字面量被改动、语义约束丢失和计数展示错误等可复现问题，补相应的小范围回归。

固定方案标识为 `mixed`，不再增加输出类型或预设编辑入口。公共规则继续要求无私有码本、无图例自解释；专业词典仍由使用者独立维护。不为追求符号密度而牺牲语义，也不将文本 token 减少称为实际账单节省。

## 范围说明

完整语义图 IR、大规模模型评测矩阵、成本平台和多候选搜索不列入当前计划。已有评测与报告工具保持可选，不扩建为使用门槛；后续扩展由具体使用问题决定。

本页替代早期工程清单，旧版本可从 Git 历史查看。旧文档中混合估算与完整请求 usage 的“真实账单压缩率”、依据数字出现就给语义绿勾，以及“零泄露”“0ms”等绝对保证均已废弃，不是待完成事项。
